# 📝 Continuous Assessments (CA)

## ♻️ CA 1: Intelligent Agent System

### Project
### 🧹 Smart 3D Lab Waste Cleaning Agent

An intelligent reflex agent designed to identify and clean waste present in a smart 3D laboratory environment.

### Concepts Used
- Simple Reflex Agent
- Agent Architecture
- Sensors and Actuators
- Environment Interaction

### Outcome
Designed a rule-based intelligent agent capable of taking actions based on current environmental conditions.

## 🌾 CA 2: Knowledge-Based Agent using Prolog

### Project

A Prolog-based expert system developed to assist farmers in identifying suitable crops and agricultural practices.

### Concepts Used
- Knowledge Representation
- Facts and Rules
- Logical Inference
- Prolog Programming

### Outcome
Built a reasoning system capable of generating recommendations using stored knowledge.
